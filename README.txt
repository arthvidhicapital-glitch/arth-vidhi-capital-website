ARTH VIDHI CAPITAL WEBSITE
==========================

Files:
- index.html : responsive one-page website
- logo.png.png: custom scalable logo artwork

PREVIEW
Open index.html in a browser. Keep the assets folder next to index.html.

PUBLISH FOR FREE (GitHub Pages)
1. On a computer or mobile browser, sign in/create an account at https://github.com/
2. Create a new public repository named arth-vidhi-capital-website.
3. Upload index.html and the entire assets folder (including assets/logo.svg) to the repository root.
4. Open repository Settings -> Pages.
5. Under Build and deployment, choose "Deploy from a branch", select branch "main" and folder "/ (root)", then Save.
6. Wait for GitHub Pages to publish. The public URL will be shown in Settings -> Pages, usually:
   https://YOUR-GITHUB-USERNAME.github.io/arth-vidhi-capital-website/
7. Open the URL on your phone to verify all sections and WhatsApp/social links.

IMPORTANT
This package is website-ready but is NOT published yet. A hosting account and publishing step are required to make it public; this workspace cannot sign into your hosting account or publish under your ownership automatically.
Before publishing, verify all contact/social links and the wording. The site intentionally does not claim SEBI registration and contains an educational-purpose disclaimer.
